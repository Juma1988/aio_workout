# Working rules for this plan

1. **One priority band at a time** — finish P0 before freelancing P3 architecture.  
2. **Verify on device** after each P0/P1 item (`flutter analyze` + manual path).  
3. **Update this file** when an item ships: mark `[x]` under acceptance criteria and add a one-line changelog entry below.  
4. **New ideas** go under P2/P3 with a reason — not straight into “now.”  
5. **Respect existing conventions:** `setState` + SharedPreferences unless we explicitly start **P3.1**; keep known filename typos (`exersise_dialog.dart`) unless a dedicated rename task is approved.
